macOS

Install it in a minute

Which download? Apple menu → About This Mac. "Chip: Apple M…" means Apple Silicon. "Processor: …Intel…" means Intel.

  1. Drag it into Applications

    Open the file you downloaded (Six-Degrees-Mac-….dmg, in your Downloads folder). In the window that opens, drag Sixgree onto the Applications folder.

  2. Open it

    Open Sixgree from Applications. Signed by Blake Burford and notarized by Apple: it opens like any Mac app. The first time, macOS asks whether to open an app downloaded from the internet: click Open.

Or install it with Terminal

Press ⌘ Space, type Terminal and press Return. Paste this line and press Return:

curl -fsSL https://raw.githubusercontent.com/blakeb056/six-degrees/main/install.sh | bash

It downloads the right version for your Mac, checks the file is exactly the one published, puts Sixgree in Applications and opens it. Running it again updates the app. Read the script.

Every release has a SHA256SUMS file (latest). To check a download yourself: shasum -a 256 ~/Downloads/Six-Degrees-Mac-*.dmg, and compare.

Windows beta

Install on Windows

The same app as on the Mac, for Windows 10 or 11 (64-bit), with the scanner's Python inside.

  1. Download it and open it

    Download Six-Degrees-Windows-Setup.exe and open it. It installs for you alone (no administrator password), adds Sixgree to the Start Menu and the Desktop, and opens it.

  2. If SmartScreen asks, run it anyway

    It isn't signed with a paid certificate yet, so Windows may say it protected your PC. Choose More info → Run anyway. Once per download.

  3. Updating

    Open a newer Setup.exe: it closes Sixgree, puts the new version in its place and opens it. Settings → Updates tells you when there is one.

Your network stays in %USERPROFILE%\.six-degrees; uninstalling (Settings → Apps) never touches it. Scanning drives Google Chrome, which it needs for that part only. This is a beta: if something doesn't work, say so on GitHub.

Linux beta

Install on Linux

On Ubuntu or Debian (64-bit), download Six-Degrees-Linux-x64.deb and install it:

sudo apt install ./Six-Degrees-Linux-x64.deb

Then open Sixgree from your apps. Elsewhere, the .tar.gz runs from its folder: on Ubuntu 24.04 and later, run sudo chown root:root chrome-sandbox && sudo chmod 4755 chrome-sandbox in it once (or start it with --no-sandbox). Scanning needs Google Chrome (not Chromium).

Or, without installing anything, run it from the Terminal with npx, which comes with Node.js: it downloads Sixgree from npm, the public library of Node.js programs, and runs it in your browser.

One command

Install Node 22.13 or later (from nodejs.org or nvm; Ubuntu's own nodejs package is too old), then run:

npx sixgree

It opens http://127.0.0.1:6363 in your browser and keeps your data in ~/.six-degrees (--data-dir puts it elsewhere; --no-open on a machine without a desktop). Stop it with Ctrl-C; update it with npx sixgree@latest. Scanning also needs Google Chrome (not Chromium), and Python 3.10 to 3.14 with venv, or the Scan page's Set up the scanner, which downloads a private copy with one click. It's tested on Ubuntu, and works on a Mac too.

Updating

Updates in one click

Choose Sixgree → Check for Updates… (or open Settings with ⌘,). Nothing checks by itself. If there's a newer version, click Install and restart: the app downloads it from GitHub, checks it against the release's published checksums and its code signature, puts it in place and opens it again. If the new version won't open, your old one is put back.

Your network isn't stored in the app, so updates never touch it, and each new version copies your data into a backups folder before it first opens it. On Linux, stop it and run npx sixgree@latest.

Troubleshooting

If something's not right

macOS says it can't check the app for malware
That's a copy from version 0.8.0 or earlier, before the app was signed. Download the newest one above (signed by Blake Burford and notarized by Apple), or allow that copy once: close the message (not Move to Trash), then System Settings → Privacy & Security → Open Anyway.
I'm not sure whether I have Apple Silicon or Intel
Apple menu → About This Mac. "Chip: Apple M…" is Apple Silicon; "Processor: …Intel…" is Intel. The Terminal line picks the right one for you.
On Linux, npx says my Node is too old
Sixgree needs Node 22.13 or later. Ubuntu's own nodejs package is older; install Node from nodejs.org or with nvm instead.
The Scan page says Chrome is missing
Scanning drives Google Chrome, installed in Applications (on Linux, Google Chrome rather than Chromium). Everything else works without it: the sample network and LinkedIn's CSV export need nothing.
How do I remove it completely?
Quit the app and drag Sixgree from Applications to the Trash. Then in Finder choose Go → Go to Folder…, paste ~/.six-degrees and move that folder to the Trash, and do the same for ~/Library/Application Support/Six Degrees.
